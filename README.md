#### 🛠️ Things I've built

| Project | What it does |

| [**NewsRing**](https://github.com/CoronRing/NewsRing) | Your own AI news feed: reads the sources, keeps what you care about, writes it in your tone. Unsponsored and open source. |
| [**EvalRing**](https://github.com/CoronRing/EvalRing) | Compare models, prompts and your own agents on the same task, with reproducible runs. `pip install evalring` |
